Here's an audit of My GLP Shot, focusing on the requested areas:

- [CRITICAL] api/app.py:171 — Timing attack vulnerability in login. The `bcrypt.checkpw` call is always executed, but the hash used depends on whether a user with the given email exists. This allows an attacker to distinguish between valid and invalid emails by measuring response times. Fix: If `user` is `None`, return `err('invalid_credentials', ...)` immediately without calling `bcrypt.checkpw`.
- [HIGH] api/Dockerfile:17 — Incorrect `chown` order in Dockerfile. The `chown -R app:app /data /app` command is executed *after* `USER app`. If `/app` is owned by root (which it typically is after `COPY`), the `app` user won't have permission to change its ownership. While `/app` is later set to `read_only: true` in `docker-compose.yml`, the `/data` directory needs to be writable by the `app` user. Fix: Move `chown -R app:app /data` before `USER app`. The `chown /app` part can be removed if `/app` is read-only.
